# ☁️ Weather App

A responsive **Weather Application** built using **React.js** that provides real-time weather information based on the user’s **current location** and also allows users to **search weather details for any city worldwide**.

---

## 📌 Project Overview

The Weather App helps users quickly check current weather conditions such as temperature, humidity, wind speed, and weather status.  
It automatically detects the user’s location using browser geolocation and also supports manual city search for global weather updates.

---

## ✨ Features

- 📍 **Current Location Weather**
  - Automatically fetches weather based on user’s location
  - Uses browser geolocation API

- 🔍 **Search Any City**
  - Get weather information for any city worldwide
  - Instant weather updates

- 🌡️ **Weather Details**
  - Temperature
  - Humidity
  - Wind speed
  - Weather condition (cloudy, rainy, sunny, etc.)

- 📱 **Responsive UI**
  - Works on desktop, tablet, and mobile devices
  - Clean and simple user interface

---

## 🛠️ Technologies Used

- **Frontend:** React.js  
- **Styling:** CSS / Bootstrap / Tailwind CSS  
- **API:** OpenWeatherMap API (or similar weather API)  
- **State Management:** React Hooks  
- **Version Control:** Git & GitHub
